# Watch List

**A Personal JustWatch Alternative Powered by TMDB**

Watch List is a fast, privacy-focused Progressive Web App for tracking movies you want to watch. No ads, no tracking, no dark patterns — just clean movie discovery powered by The Movie Database (TMDB) API.

## Features

- 🎬 **Watchlist Management** — Add and remove movies from your personal watchlist
- 🔍 **TMDB Search** — Search for any movie with real-time results
- 📺 **Streaming Info** — See which services are streaming each title
- 📱 **PWA Support** — Install on any device as a native app
- 🌙 **Dark Theme** — Easy on the eyes with a modern dark interface
- 🎲 **Random Pick** — Can't decide? Get a random suggestion from your watchlist
- 📋 **Multiple Views** — Grid and list view options for browsing

## Prerequisites

You need a free TMDB account with:

1. **API Key** — from [TMDB API settings](https://www.themoviedb.org/settings/api)
2. **Session ID** — generated by authenticating via the [TMDB API](https://developer.themoviedb.org/reference/authentication-how-do-i-generate-a-session-id)

## Deploying on Vercel (Recommended)

1. Fork this repository
2. Import the project in [Vercel](https://vercel.com)
3. Add the following environment variables in your Vercel project settings:

   | Variable | Description |
   |----------|-------------|
   | `TMDB_API_KEY` | Your TMDB API key |
   | `TMDB_SESSION_ID` | Your TMDB session ID |
   | `ADULT_PIN` | *(Optional)* PIN to unlock the adult section |

4. Deploy — Vercel runs `build.js` automatically, which injects your credentials into the app at build time

## Local Development

```bash
# Clone the repository
git clone https://github.com/josefresco/watch-list.git
cd watch-list

# Build with your credentials
TMDB_API_KEY=your_key TMDB_SESSION_ID=your_session node build.js

# Serve the output
npx serve dist
```

Open `http://localhost:3000` in your browser.

## Configuration

### Streaming Services

Edit the `MY_SERVICES` array in `index.html` to match your subscriptions. These services are highlighted in the streaming providers list:

```javascript
const MY_SERVICES = [
  "netflix",
  "hulu",
  "disney",
  "max",
  // Add your services here
];
```

### Excluded Providers

Some providers can be hidden from the streaming list entirely. Edit `EXCLUDED_PROVIDERS` in `index.html`:

```javascript
const EXCLUDED_PROVIDERS = new Set([
  "amazon channel",
  // Add providers to hide here
]);
```

## How the Build Works

`build.js` reads `index.html`, replaces credential placeholders (`%%TMDB_API_KEY%%`, `%%TMDB_SESSION_ID%%`, `%%ADULT_PIN%%`) with your environment variable values, and writes the result to `dist/index.html`. Vercel serves from `dist/`.

Your credentials are never stored in the repository — only in your Vercel project's environment variable settings.
